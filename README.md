# دفتر پروژه · SEO Afghanistan

برنامهٔ گزارش‌دهی مدیران پروژه. مدیران پروژه تسک‌ها را مرحله‌به‌مرحله ثبت می‌کنند و ناظران می‌خوانند.

## فایل‌ها
- `index.html` — خود برنامه
- `config.js` — تنظیمات Firebase (باید پر شود)
- `firestore.rules` — قوانین امنیتی (در Firebase کپی شود)

## نقش‌ها
- **در انتظار** — تازه ثبت‌نام کرده؛ مدیر سیستم باید نقش بدهد
- **مدیر پروژه** — پروژه‌های خودش را می‌نویسد
- **ناظر** — همه را می‌خواند، چیزی را تغییر نمی‌دهد
- **مدیر سیستم** — همه‌چیز، به‌علاوهٔ تعیین نقش‌ها
- **مسدود** — دسترسی ندارد
